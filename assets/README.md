# Release artwork

- `github-banner.png`: wide 2:1 repository/README banner.
- `x-flyer.png`: portrait 4:5 promotional flyer for X and other social channels.
- `generation-prompts.json`: the exact prompts used to create both assets.

Both final assets were created with the built-in Imagegen tool and visually checked for product name, feature labels, and readable text. No external logos, screenshots, private projects, measured performance claims, or third-party artwork were included. The files are original project release assets distributed under this repository's license, subject to applicable rights in AI-generated material.

The banner can be used directly in the README. A repository host may require a particular pixel size for its social-preview settings; resize with the owner's normal design tool if needed. The portrait flyer is intended as an attached image, with the repository/release URL in the accompanying post.


## Versioning note

Artwork is promotional, not the capability contract. Developer Harness 2.0 capabilities and boundaries are defined by the root README, `docs/CAPABILITIES.md`, `docs/REFERENCE.md`, and the release notes. Regenerate artwork before using it for any version-specific feature claim that is not visibly present in the asset.
