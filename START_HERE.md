# Let your AI set up Developer Harness

Tell your AI what you build, which tools you use, and how you prefer to work. It should read the [personalization protocol](developer_harness/resources/START_HERE.md), inspect the project, and handle the setup.

Copy this into your AI coding tool:

> Read START_HERE.md and its personalization protocol. Install and personalize Developer Harness for this workspace. Inspect what already exists, preserve owner instructions, configure real validation commands, and create a useful first task and restart packet. My intended use is: [describe it].

When installing into another repository, name its path. When the AI lacks terminal or file access, it should produce the exact installation plan and explain the missing access, rather than claim it installed anything.
